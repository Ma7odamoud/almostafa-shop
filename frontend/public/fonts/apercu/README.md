# Apercu Fonts Directory

This directory is wired to load licensed Apercu font files:
- Apercu-Regular.woff2 (weight 400)
- Apercu-Medium.woff2 (weight 600)
- Apercu-Bold.woff2 (weight 700)

Dropping these three woff2 files into this folder will immediately activate Apercu on English pages across the site with no code edits.
Until these files are provided, the site falls back to the existing typography ('Cormorant Garamond', 'Amiri', Georgia, serif) with the exact Concrete size and weight scale.
