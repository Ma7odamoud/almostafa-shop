# Showroom / Tailor Measurement Photo

Drop your high-resolution showroom or tailor measurement photo here:
- Recommended path: `/assets/showroom/showroom.jpg` or `/assets/showroom/showroom.webp`
- File size target: under 200 KB

When this file is present, the visit section displays it alongside the map panel.
When absent, a bespoke tailor measurement SVG artwork is rendered as placeholder.
