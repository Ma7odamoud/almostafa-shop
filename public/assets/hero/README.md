# Hero Asset Directory

Drop your high-resolution hero photo of a man in a tailored suit here:
- Recommended path: `/assets/hero/hero.jpg` or `/assets/hero/hero.webp`
- Recommended aspect ratio: 4:5 on mobile, 16:9 on desktop
- File size target: under 150 KB for mobile

When this file is present, the hero section will display it full-bleed with the navy gradient overlay.
When absent, the hero displays a navy-to-darker-navy gradient with a subtle needle and thread bespoke motif.
